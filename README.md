# 콩으니 카드뉴스 생성 에디터

카카오톡 테마 캡처를 인스타그램 카드뉴스로 꾸미는 Windows 데스크톱 프로그램입니다.

## 다운로드

[최신 배포본 받기](https://github.com/rkclrns/kongeuni-card-editor/releases/latest)

- **Setup.exe**: 내 계정에 설치하고 시작 메뉴/바탕화면 바로가기를 만듭니다. 관리자 권한이 필요 없습니다.
- **Portable.zip**: 압축을 모두 푼 다음 `KongeuniCardEditor.exe`를 실행하세요. fonts와 licenses 폴더도 함께 보관하세요.
- Windows 10/11, .NET Framework 4.8이 필요합니다. 갈무리11 Regular/Bold 서체가 포함되어 있습니다.
- 현재 배포본은 코드 서명 인증서로 서명되지 않았습니다. Windows에서 게시자를 확인할 수 없다는 안내가 나올 수 있습니다. 공식 저장소의 파일인지와 `SHA256SUMS.txt`를 확인하세요.

## 사용하기

1. [캡처]에서 이미지를 불러오거나 이미지를 붙여 넣으세요.
2. 제목, 배경/패턴, 캡처 테두리, 말풍선을 꾸미세요. 캔버스 요소를 클릭하면 해당 설정이 열립니다.
3. [서명]의 AND 지원을 켜면 오른쪽 위 `IOS`가 `IOS/AND`로 바뀝니다.
4. PNG로 저장하세요. 출력은 1080×1080 / 1080×1350 / 1080×1920입니다.

처음에는 `New Name`과 회색 정사각형이 표시됩니다. 개인 대화 샘플은 포함하지 않았습니다.

제목·서명·말풍선의 폰트/색/테두리/그림자/네온, 그라데이션, 캔버스 스포이드, 엇갈린 도트/별/하트, 말풍선 반전과 Shift 비율 조절, 실행 취소/다시 실행을 지원합니다. 자세한 내용은 [사용법.txt](사용법.txt)를 확인하세요.

이미지는 PC 안에서 처리됩니다. 서버 업로드나 AI API를 사용하지 않습니다. **편집 가능한 작업 파일 저장 기능은 아직 없습니다. 종료 전에 PNG를 저장하세요.**

## 소스 빌드

Windows PowerShell에서:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Windows에 포함된 .NET Framework C# 컴파일러를 사용합니다. 추가 NuGet 패키지나 SDK 다운로드는 필요 없습니다. 결과물은 `dist/`, 테스트 결과와 화면은 `work/self-test/`에 생성됩니다.

버전 태그 `v*`를 푸시하면 GitHub Actions가 빌드와 자체 테스트 후 설치본/무설치 ZIP/체크섬을 Release에 게시합니다. 태그 버전과 소스/설치 프로그램 버전은 함께 수정하세요.
