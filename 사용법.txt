콩으니 카드뉴스 생성 에디터 · 1.0.0

실행: KongeuniCardEditor.exe를 더블클릭하세요.
Windows 10/11, .NET Framework 4.8용입니다. API 키는 필요하지 않습니다.
UI는 동봉한 Galmuri11 Regular를 사용합니다.
Portable ZIP은 전체 압축을 풀고 fonts 및 licenses 폴더도 함께 보관하세요.

처음 실행했을 때
- 테마 이름: New Name.
- 캡처 자리: 회색 정사각형. 기존 대화 샘플과 말풍선은 비워져 있습니다.
- 분홍 별 배경과 캡처 위/제목 아래 기본 배치는 유지합니다.
- [캡처] 탭에서 본인의 캡처를 불러와 시작하세요.

오른쪽 위 플랫폼 표시
- 기본값은 IOS입니다.
- [서명] 탭의 [AND도 지원 (IOS/AND)]을 체크하면 IOS/AND로 바뀝니다.
- 체크를 해제하면 다시 IOS만 표시됩니다.
- 오른쪽 위 플랫폼 문구를 클릭해도 [서명] 설정으로 이동합니다.
- 작은 '콩으니 카톡테마'와 같은 서체, 색상, 테두리, 그림자/네온 스타일을 사용합니다.
- 문구 길이가 바뀌어도 오른쪽 정렬은 유지됩니다.
- 이 체크 변경도 실행 취소/다시 실행할 수 있습니다.

요소를 클릭하면 왼쪽 설정이 열립니다.
- 제목 클릭 → [제목].
- 배경 클릭 → [배경].
- 캡처 클릭 → [캡처].
- 작은 '콩으니 카톡테마' 클릭 → [서명].
- 말풍선 클릭 → [말풍선].
오른쪽에 있던 말풍선 설정도 왼쪽으로 옮겼습니다.
탭을 직접 눌러 전환해도 됩니다. 아래쪽 옵션은 왼쪽 패널을 스크롤하면 보입니다.

제목 크기 고정
- 제목 크기는 고정하고 크기 슬라이더와 크기 조절점을 제거했습니다.
- 제목은 드래그로 위치를 옮길 수 있으며 문구/폰트/색/효과는 바꿀 수 있습니다.
- 제목 글자에 들어가는 폰트 크기는 위쪽 이름 85px, 아래쪽 '카톡테마 공유' 91px입니다.
  서체와 볼드/기울기 여부에 따라 실제 글자 폭은 달라질 수 있습니다.
- 긴 제목이 캔버스 밖으로 넘치면 문구를 줄이거나 폭이 좁은 서체를 선택하세요.

볼드 · 기울기 · 테두리 · 그림자 · 네온
- 제목, 서명, 말풍선 글자에 각각 독립적으로 적용됩니다.
- 각 요소 설정에 있는 체크박스로 켜거나 끌 수 있습니다.
- 테두리 색/두께, 그림자 거리/진하기, 네온 색/퍼지는 크기/진하기를 조절할 수 있습니다.
- 말풍선은 [말풍선 글자 효과]까지 아래로 스크롤하세요.
  '말풍선 도형 그림자'와 '글자 그림자'는 서로 다른 설정입니다.
- 폰트에 해당 굵기/기울기 스타일이 없으면 가능한 스타일이나 합성 효과로 표현합니다.
- Galmuri11 Regular에서 볼드를 켜면 동봉한 Galmuri11 Bold를 사용할 수 있습니다.
- 글자 테두리 두께는 글자 크기를 자동으로 줄이지 않습니다.
- 큰 글자가 말풍선 밖으로 나오면 말풍선을 늘리거나 직접 줄바꿈하세요.

Shift로 비율 조절
- 말풍선을 클릭하고 점선 네모의 오른쪽 아래 조절점을 드래그하세요.
- Shift 없이 드래그하면 말풍선의 가로/세로만 조절하고 글자 크기는 유지합니다.
- Shift를 누른 채 드래그하면 원래 비율을 유지하면서 문구의 글자 크기도 같이 커집니다.
- 캡처의 조절점을 드래그하면 원본 가로세로 비율을 유지하며 크기가 바뀝니다.
- 서명의 조절점을 드래그하면 문구가 균일하게 커집니다.
- 제목은 크기가 고정되어 조절점이 없고 이동만 가능합니다.
- 최대/최소 크기에 도달하면 더 이상 커지거나 작아지지 않습니다.

캔버스 직접 스포이드
1. 바꾸려는 색상칸을 클릭하세요.
2. 색상창의 [캔버스 스포이드]를 누르세요.
3. 색상창이 잠시 숨겨지며 현재 카드 안에서 직접 색을 고를 수 있습니다.
4. 커서를 옮기면 확대된 픽셀과 HEX를 볼 수 있고, 클릭하면 색이 선택됩니다.
5. 원래 색상창으로 돌아오면 [적용]으로 확정하세요.
- 스포이드 중 Esc 또는 우클릭은 채취만 취소하고 색상창으로 돌아갑니다.
- 색상창 자체에서 [취소]하면 이번 색상 편집 전체를 원래대로 되돌립니다.
- 별도의 이미지/스포이드 창을 띄우지 않습니다.
- 원본 전체나 다른 앱이 아니라, 지금 출력 규격 안에 배치된 실제 카드에서 색을 추출합니다.
- 선택 테두리와 조절점, 스포이드 확대경은 추출 대상이나 PNG에 포함되지 않습니다.
- 그라데이션은 시작색/끝색을 먼저 고른 뒤 스포이드를 사용하세요.

가로 가운데 정렬
- [캡처] 탭의 [가로 가운데 정렬]을 누르세요.
- 가로 위치만 가운데로 맞추고 세로 위치와 크기는 유지합니다.

기존 기능
- 배경: 단색, 격자, 엇갈린 도트/별/하트.
- 각 요소 옆 색상칸에서 단색과 그라데이션을 편집하고 실제 카드에서 미리 볼 수 있습니다.
- 폰트는 검색 목록과 샘플, 실제 카드에서 미리 보고 적용하거나 취소할 수 있습니다.
- 말풍선: 둥근형, 타원, 생각 구름, 외침, 리본, 네모, 동그라미.
- 말풍선 모양만 좌우 반전하고 글자는 그대로 유지합니다.
- 말풍선 복제/삭제/앞뒤 순서, 도형/글자 색과 선 두께를 조절할 수 있습니다.
- 슬라이더 위의 휠로 값이 바뀌지 않고 설정 패널만 스크롤됩니다.
- 수치는 무채색 슬라이더, 좌우 화살표, 숫자 직접 입력으로 조절합니다.
  숫자 입력 후 Enter 또는 다른 곳을 클릭하면 적용됩니다.
- 실행 취소는 최대 60단계입니다. Shift 확대, 효과, 정렬, 색상 적용도 포함됩니다.

단축키와 저장
- Ctrl+O: 캡처 불러오기 / Ctrl+S: PNG 저장.
- Ctrl+Z: 실행 취소 / Ctrl+Y 또는 Ctrl+Shift+Z: 다시 실행.
- Ctrl+V: 이미지 붙여넣기(텍스트 입력란 밖에서).
- 선택한 말풍선: 방향키 1px, Shift+방향키 10px 이동, Delete 삭제.
- 지원 입력: PNG/JPG/JPEG/BMP/GIF 첫 프레임. 파일 드롭도 가능합니다.
- 출력: 1080×1350 / 1080×1080 / 1080×1920 PNG.
- 선택 표시와 조절점은 저장되지 않습니다. 캔버스 밖으로 나간 부분은 잘립니다.
- 사진은 이 컴퓨터 안에서만 처리합니다. API나 대화 내용 인식은 사용하지 않습니다.
- 작업 파일 저장과 일괄 출력은 아직 없습니다. 닫기 전에 PNG를 저장하세요.

소스와 빌드
GitHub 저장소의 소스와 build.ps1로 다시 빌드할 수 있습니다.
갈무리11 Regular/Bold가 동봉되어 별도 설치 없이 사용할 수 있습니다.
폰트가 없으면 맑은 고딕으로 대체됩니다.
